🎓 CLASSIFICATION DETAILS

Classes Supported: 4
   🔴 Pituitary - Pituitary gland tumors
   🔵 Glioma - Brain cell tumors  
   🟣 Meningioma - Brain membrane tumors
   ✅ No Tumor - Healthy MRI scan

Model Architecture
   Base: VGG16 (Transfer Learning)
   Input: 128×128 RGB images
   Output: 4-class probabilities (softmax)
   Training: Fine-tuned on brain tumor dataset

Risk Assessment
   ≥ 85% confidence → 🔴 High risk
   65-84% confidence → 🟡 Medium risk
   < 65% confidence → 🟢 Low risk

🆘 QUICK TROUBLESHOOTING

Problem: ModuleNotFoundError
→ Solution: pip install -r requirements.txt

Problem: Model not found
→ Solution: Ensure model.keras exists in project root

Problem: App won't start
→ Solution: streamlit cache clear && streamlit run app.py

Problem: Port already in use
→ Solution: streamlit run app.py --server.port 8502

Problem: Slow first load
→ Solution: This is normal - model caches after first load
